## ✨ Features

- ⚡ **Zero-Dependency Architecture:** Blazing fast load times built with semantic HTML5, modern vanilla CSS3, and JavaScript.
- 📱 **Fully Responsive:** Fluid design tailored for mobile phones, tablets, laptops, and ultra-wide desktop screens.
- 🔍 **Live Search & Category Filtering:** Instant product filtering by category (Laptops, Components, Peripherals, Displays) and keyword matching.
- 🛒 **Interactive Cart Simulation:** Live cart counter badge with smooth toast notifications.
- 🎨 **Brand Design System:** High-contrast emerald green & bold red aesthetic with modern typography (Montserrat, Orbitron).
- 📍 **Store Locations & Direct Contacts:** Complete branch information for Embilipitiya & Padalangala with instant call and WhatsApp connectivity.
- 🚀 **GitHub Actions Automated Deployment:** Configured with GitHub Actions workflow for automatic deployment to GitHub Pages on push to `main`.

## 🛠️ Local Development

To run and preview the project locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Mathiyass/infonet-web.git
   cd infonet-web
   ```

2. **Open in browser:**
   - Simply double click `index.html` or open it with your favorite browser.
   - Alternatively, use any local server (e.g. VS Code Live Server or `npx serve` / `python -m http.server 8000`).

## 🚀 GitHub Pages Configuration

This repository includes an automated GitHub Actions deployment workflow (`.github/workflows/deploy.yml`).

### To enable GitHub Pages on GitHub:
1. Go to your repository on GitHub: **[Mathiyass/infonet-web](https://github.com/Mathiyass/infonet-web)**
2. Navigate to **Settings** > **Pages**
3. Under **Build and deployment** > **Source**, select **GitHub Actions**
4. Any push to the `main` branch will automatically build and publish the live site to:
   👉 **https://mathiyass.github.io/infonet-web/**
